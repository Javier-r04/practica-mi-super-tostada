Cápsula de estado con color fijado por enum: pedido, cobranza, cola offline y punto de carga.

```jsx
<EstadoBadge estado="EN_PRODUCCION" />
<EstadoBadge estado="SIN_SINCRONIZAR" size="sm" />
```

No inventes estados nuevos ni recolorees los existentes: el color es parte del vocabulario compartido con Alex, Carla y Tony.
