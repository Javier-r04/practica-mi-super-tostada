Icono del sistema: envuelve un glifo de Lucide (2px de trazo) y lo dimensiona.

```jsx
<Icon name="truck" size={20} />
<Icon name="banknote" size={16} color="var(--green-700)" />
```

Nombres en uso frecuente: `clipboard-list` (pedidos), `factory` (producción), `store` (tienda), `truck` (reparto), `banknote` (efectivo), `arrow-left-right` (transferencia), `receipt-text` (factura/DTE), `message-circle` (WhatsApp), `clock` (ventana), `cloud-off` (offline).
