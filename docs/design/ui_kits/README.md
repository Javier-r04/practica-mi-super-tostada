# UI kits

Tres superficies del sistema de pedidos y cobranza:

- `panel/` — panel interno de escritorio (Cristian, Carla, Alex).
- `portal/` — portal público del cliente en `/p/{token}`, móvil.
- `reparto/` — PWA de reparto con cola offline (Tony), móvil.

**Importante:** no existía interfaz previa ni repositorio al construir este sistema. Estos kits se derivan del documento `CLAUDE.md` del proyecto (dominio, roles, reglas de negocio) y del material promocional entregado. Son propuestas fieles a esas reglas, no recreaciones de una pantalla existente.
